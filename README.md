## Pokedex JS
Bem-vindo à Pokédex JavaScript, um projeto que simula a clássica enciclopédia de Pokémon, permitindo visualizar informações detalhadas de cada criatura.

## 🚀 Sobre o projeto

Esta aplicação consome dados de uma API pública de Pokémon e exibe:

Nome
Número (ID)

## 🧠 Objetivo

### Este projeto foi desenvolvido para:

Praticar consumo de API (fetch/async/await)

Manipulação de DOM

Organização de código em JavaScript

Construção de portfólio frontend

## 🛠️ Tecnologias utilizadas

HTML5

CSS3

JavaScript (ES6+)

API REST (PokéAPI)

## 📦 Funcionalidades

🔍 Buscar Pokémon por nome ou ID

📄 Listagem de Pokémon

📱 Interface responsiva

⚡ Carregamento dinâmico via API

## 📚 Aprendizados

### Durante o desenvolvimento, foram reforçados conceitos como:

Promises e requisições assíncronas

Manipulação de eventos

Estruturação de projetos frontend
